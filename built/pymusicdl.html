pymusicdl

An open-source Python tool: type a song name or paste a playlist, get the music.

What it is

Songs from a name or a link

pymusicdl downloads a song from its name, a YouTube playlist, a Spotify playlist or a whole album. It is a command line tool written in Python and released under the MIT licence.

What I learned

Shipping to strangers
